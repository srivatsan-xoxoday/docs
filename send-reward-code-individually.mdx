## About Reward Codes

A Xoxo code is a 16-digit alphanumeric code that provides a fast and secure method to send unique codes to different participants in your ecosystem, regardless of their location.

**Example code format:** S1H2-R3E4-D5I6-S7T8B

### Key Features

- Allows guest checkout (recipient doesn't need to log in)
- Allows partial redemption
- Can be combined with up to 10 codes for a single checkout

### Best fit if you want to:

- Allow easy redemption from our marketplace without account creation
- Enable partial redemption or combining codes for larger rewards
- Launch campaigns with unique landing pages and reward catalogs
- Set expiry dates tailored to campaign duration and needs

## Send Reward Code Individually

Follow these steps to send reward codes one at a time:

### Step 1: Configure Redemption Settings

Click on **Reward Codes** in the admin dashboard and select your preference for "Choose who can redeem" under settings.

**Three redemption options:**

<Accordion title="Only the recipient of the code" defaultOpen={false}>
  The recipient (and their email address) you specify when sending the reward code—for example, [john.smith@acme.com](mailto:john.smith@acme.com)—is the only person who can use it to collect vouchers on that specific email address.

  **Best for:** Direct sends to ensure the right person gets rewarded.
</Accordion>

<Accordion title="Only users with same domain as yours" defaultOpen={false}>
  If your email is [john.doe@xyz.com](mailto:john.doe@xyz.com), only email addresses on the same domain (xyz.com) can use the reward code.

  **Best for:** Sending codes to people who might share them.
</Accordion>

<Accordion title="Any user with the code" defaultOpen={false}>
  Any user with the code can redeem it against your pre-funded wallet.

  **Note:** This is the least secure option and should be used only when necessary.
</Accordion>

### Step 2: Enter Recipient Details

Select the **Send Individually** tab and enter:

- Recipient name
- Email address
- Reward code value

#### Advanced Settings

- **Schedule sends:** Schedule reward sends to a future date (sent at 12 AM UTC)
- **Personal message:** Add a custom message to the email body for the recipient
- **Internal reference note:** Add a note to yourself for later recall

### Step 3: Set Expiry and Customize Messages

Set an expiry date (default is 12 months, or customize as needed) and customize email and SMS messages as required.
