# Send Reward Code: Bulk Upload

## About Reward Codes

A Reward Code is a 16-digit alphanumeric code that provides a fast and secure method to send unique codes to different participants in your ecosystem, regardless of location. Example: `S1H2-R3E4-D5I6-S7T8B`

### Key Features

- Allows guest checkout (recipient doesn't need to log in)
- Allows partial redemption
- Can combine up to 10 codes for a single checkout

### Best Use Cases

- Enable easy redemption from your marketplace without account creation
- Support partial redemption or combining codes for larger rewards
- Launch campaigns with unique landing pages and reward catalogs
- Set expiry dates tailored to campaign duration and needs

## Send Reward Codes in Bulk

<Tip>
  Download the available template directly from the dashboard for your convenience.
</Tip>

### Step 1: Access Reward Code Settings

Click on the **Reward Code** section in the admin dashboard (under Settings) and configure **"Choose who can redeem"** settings.

### Step 2: Select Who Can Redeem

Choose one of three redemption options:

<AccordionGroup>
  <Accordion title="Only the recipient of the code">
    The specified recipient (by email address) can use the Reward Code. For example, if you send the code to `john.smith@acme.com`, only that person can redeem it on that email address. Best for direct sends to ensure the right person gets the reward.
  </Accordion>

  <Accordion title="Only users with same domain as yours">
    Only email addresses on the same domain as yours can use the code. For example, if your email is `john.doe@xyz.com`, only users with `xyz.com` domain addresses can redeem. Recommended if you're sending codes to people who might share them.
  </Accordion>

  <Accordion title="Any user with the code">
    Any user with the code can redeem it against your pre-funded wallet. This is the least secure option and should be used only when necessary.
  </Accordion>
</AccordionGroup>

### Step 3: Upload Recipient List

Prepare a list of recipients in CSV format and upload it in one shot. You can download the template directly from the Admin portal.

### Step 4: Set Expiry and Customize Messages

Set an expiry date (default is 12 months, or set a custom duration) and customize email and SMS messages as needed.
