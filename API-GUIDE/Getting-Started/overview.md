## Xoxoday API Reference

Xoxoday’s developer platform is designed to help you:

- Embed rewards seamlessly into your applications
- Drive engagement, loyalty, and revenue growth
- Customize every step of the reward journey

All APIs follow REST conventions with predictable URL structures, use standard HTTP methods (GET, POST, PUT, DELETE), and return clean JSON responses.
The base URL for all requests is:

https://accounts.xoxoday.com/chef

## Integration Options

Xoxoday offers multiple integration approaches so you can choose what works best for your business and customer experience goals.

### Rewards API

A powerful, programmatic way to access Xoxoday’s global catalog of rewards — including:

1.  **Gift Cards**
2.  **Merchandise**
3.  **Perks**
4.  **Charity**
5.  **Lounge**
6.  **Mobile Top-up**

Best for:

-   Full control of the front-end and UI
-   Embedding the reward experience natively into your app
-   Managing the end-to-end user flow via simple REST APIs

> Learn [how to send your first Reward](https://developers.xoxoday.com/v1.2/docs/reward-api).

### Storefront Integration

Redirect users to Xoxoday’s hosted storefront via SSO or SAML authentication. Users can browse and redeem rewards directly, while your platform handles the points distribution.

Best for:

1.  Using your native points engine while offloading catalog & fulfillment to Xoxoday
2.  Quick integration with minimal development effort
3.  Automatically syncing points balance and redemption data

Learn [how to setup storefront integration](https://developers.xoxoday.com/v1.2/docs/storefront-integrations)

### RewardLink API

Automate the delivery of personalized reward links that open to a curated catalog of reward choices.

Best for:

1.  Sending rewards instantly via email, SMS, or chat
2.  Offering a pre-selected, branded set of reward options
3.  Quick, lightweight reward fulfillment

Learn [how to send your first Reward Link](https://developers.xoxoday.com/v1.2/docs/reward-links)

### Reward Points API

Send points directly to your users so they can redeem them in the Xoxoday ecosystem.

Best for:

1.  Loyalty programs
2.  Employee engagement platforms
3.  Flexible reward budgeting

Learn [how to send your first Reward points](https://developers.xoxoday.com/v1.2/docs/reward-points).

With these integration options, you can start small and scale your reward program without changing your core architecture.
